# Stage-Aligned 30s Windowing with Lagged SpO2 Context and Rolling Baseline Normalization

We slice each Recording into non-overlapping 30-second Windows aligned 1-to-1 with `<id>_stage.txt` epochs, labeling a Window as apnea (`1`) when definite Apnea events (`APNEA-O/C/M`, `HYP-O/C/M`) overlap by at least 5.0 seconds (`PB` and `POSSIBLE` are excluded). Because finger pulse oximetry exhibits a 10–30 second circulatory delay relative to airflow cessation, and clinical hypopnea scoring relies on relative drops from local baseline breathing rather than raw sensor units, feature extraction augments each 30s Window with a configurable post-window SpO2 look-ahead (`+15s`), a centered 120s RR-interval HRV context window, and 5-minute rolling baseline ratios before applying a train-only `StandardScaler`.
